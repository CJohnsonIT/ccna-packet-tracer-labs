# Cisco CCNA Packet Tracer Labs

This repository documents the networking labs I am completing while studying for the Cisco CCNA.

My goal is to practice configuring, verifying, and troubleshooting networks while building a stronger foundation in routing, switching, IPv4 addressing, subnetting, and other CCNA topics.

## Topics

As I progress through my CCNA studies, this repository will include labs involving:

- IPv4 addressing and subnetting
- Ethernet switching
- VLANs
- 802.1Q trunking
- Inter-VLAN routing
- Static routing
- OSPF
- DHCP
- NAT
- ACLs
- Network device management
- Connectivity troubleshooting

## Labs

### 01 - Basic LAN Connectivity

Build and troubleshoot a basic LAN containing a Cisco router, two switches, four workstations, and a server.

Topics practiced:

- Static IPv4 addressing
- Default gateways
- Cisco IOS interface configuration
- ICMP connectivity testing
- Interface verification
- Basic network troubleshooting
